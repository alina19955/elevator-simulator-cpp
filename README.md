# Elevator Simulator

Симулятор работы группы лифтов в многоэтажном здании.

## Возможности

- работа нескольких лифтов;
- диспетчеризация вызовов;
- выбор ближайшего лифта;
- имитация движения;
- обработка очередей вызовов;
- логирование событий.

## Технологии

- C++
- ООП
- STL
- Makefile

## Сборка

```bash
make
./elevator_simulator
```

## Структура проекта

- `src/` — исходные файлы
- `include/` — заголовочные файлы
